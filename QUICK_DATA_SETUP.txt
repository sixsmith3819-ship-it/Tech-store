TROUBLESHOOTING:

Q: Products not showing?
A: 1. Refresh browser
   2. Clear cache (Ctrl+Shift+Delete)
   3. Check SQL ran successfully

Q: SQL script failed?
A: 1. Make sure RLS_FIX script ran first
   2. Copy entire script carefully
   3. Check for database connection issues

Q: Admin login not working?
A: 1. Need to sign up first (creates auth.users)
   2. Then update profile to role='admin'
   3. Or use Supabase dashboard to create user manually

Q: Products showing wrong prices?
A: 1. Verify SQL ran completely
   2. Try clearing browser cache
   3. Check database directly in Supabase
