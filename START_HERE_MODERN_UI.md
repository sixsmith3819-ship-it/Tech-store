## 🔧 Customization

### Change Primary Color
Edit `tailwind.config.ts`:
```typescript
colors: {
  oracle: {
    500: '#NEW_HEX_CODE', // Change this
    600: '#DARKER_HEX',
    // ...
  }
}
```

### Adjust Animation Speed
```typescript
keyframes: {
  float: {
    // Change '3s' to 2s or 4s
  }
}
```

### Modify Glow Color
Find in `tailwind.config.ts`:
```typescript
boxShadow: {
  glow: '0 0 20px rgba(14, 165, 233, 0.5)',
  // Change RGB values: (R, G, B)
}
```
